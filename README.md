# Portafolio

Nombre del proyecto: Portafolio de Alirio
Descripción del proyecto: pagina web realizada a traves de VS Code como herramienta para elaborar la progamcación del apartado de HTML y CSS que se uso en la refinacion de la página web.
Tecnologías y técnicas usadas: Se utilizo tanto HTML como su respectivo CSS para realizar este proyecto, en el CSS se uso de tecnologia responsiva para que esta pagina web pueda visualizarse en diferentes dispositivos de diferentes tamaño de pantalla.
